03

Timeline 至 GA

单人 + AI 协作的现实节奏。MVP 第 4 个月可内部自用,~12 个月到 GA。团队扩到 2–3 人可压到 7–8 个月。

Week 1–4
Month 1

Phase 0 — Foundation

出口:Schema 定稿、Postgres+Firebase 脚手架跑起来、合规规格落地。

  • ✅ Design Matrix
  • ✅ Data Model + schema.sql
  • Compliance Spec
  • Architecture
  • PRD(分模块)
Week 5–18
Month 2–4.5

Phase 1 — MVP(单实体闭环)

出口:一家公司能完整记账 + 合法开 e-Invoice + 出三表。可内部自用。

  • Double-entry ledger
  • Chart of Accounts
  • Sales/Purchase Invoicing
  • MyInvois 原生提交
  • SST
  • Trial Balance / P&L / BS
  • RBAC
  • Audit trail
Week 19–32
Month 5–8

Phase 2 — Beta(跨境 + 自动化)

出口:多实体合并、多币种、银行对账自动化、可从旧系统迁入。

  • Multi-entity + consolidation
  • Multi-currency
  • Peppol
  • Bank feed + auto-reconcile
  • AI categorization
  • Open API + webhooks
  • Migration tool(AutoCount/SQL)
  • MPERS/MFRS 报表
Week 33–52
Month 9–12

Phase 3 — GA(深度 + 上市)

出口:深度库存、自助 onboarding、合作伙伴体系、定价分层、安全加固。

  • Inventory / manufacturing
  • POS integration
  • n8n native nodes
  • OCR 单据提取
  • Custom report builder
  • Self-serve onboarding
  • Partner Program
  • Pen-test + data residency
CRITICAL PATH  MyInvois / Peppol 认证是 LHDN/MDEC 的外部流程,有审批 lead time,不是写代码就行。Phase 0 就要并行启动申请,否则会卡死 Phase 1 上线。
